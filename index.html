⚙️ Why 2Gbps + 2Gbps — TIME Infrastructure & Migration Constraints

The current 50Mbps line is an Internet Direct (ID) Leased Line — a legacy dedicated-circuit product that operates on a completely separate network infrastructure from TIME's FTTO fibre platform. When this ID service is cancelled, the dedicated port allocation and circuit provisioning on TIME's network are permanently released. There is no migration path or capacity transfer from the ID platform to FTTO — they are distinct product families with different underlying transport.

The existing 1Gbps is FTTO Business tier — this product uses a different ONT (Optical Network Terminal) and is provisioned on TIME's shared business GPON segment, which supports a maximum throughput of 1Gbps per port. The FTTO Business ONT hardware does not support 2Gbps or 10G handoff. An in-place speed upgrade from 1Gbps Business to 2Gbps Enterprise is not possible without replacing the terminal equipment, re-provisioning the port on the OLT (Optical Line Terminal), and issuing a new service order — effectively a new installation.

FTTO Enterprise 2Gbps requires dedicated equipment per line:

• A Huawei FTTO Router with 10G SFP+ interface — this is Enterprise-grade hardware not interchangeable with the Business-tier ONT currently installed

• A new service ID, new port provisioning on TIME's OLT, and a separate 36-month service agreement per connection

• Each line is independently routed on TIME's backbone for physical path diversity

Because the ID leased line and the FTTO Business line both need to be decommissioned (the ID line is being cancelled, and the Business-tier ONT cannot support Enterprise speeds), TIME's standard migration pathway requires two fresh FTTO Enterprise installations to restore dual-line redundancy. This is not an optional upgrade — it is a platform migration driven by the hardware and network architecture differences between the legacy setup and the target Enterprise configuration.

✓ Lowest cost (RM 623/mo)

✓ Highest monthly savings (85%)

✕ No redundancy — single point of failure

✕ Hotel has zero internet if line goes down

✕ Not suitable for hospitality operations

Scenario B — Mixed Tiers

✓ Dual-line redundancy

✓ Lower OTC (RM 3,000)

✕ Asymmetric failover — drops to 1Gbps if 2G line fails

✕ Two different service tiers (Business + Enterprise)

✕ Legacy Business ONT stays — different hardware/management

✕ 1Gbps line is month-to-month — TIME may reprice or discontinue

✕ Will eventually need to migrate 1G to Enterprise anyway

Scenario C — Full Enterprise ★

✓ Symmetric dual-line (2G + 2G) — both lines equal

✓ Full-speed failover (2Gbps maintained if one line drops)

✓ Unified Enterprise tier — single platform, consistent SLA

✓ Both lines on new Huawei 10G hardware

✓ 4Gbps total · best cost-per-Gbps (RM 312/Gbps)

✓ Clean migration — no legacy equipment left behind

✓ TIME's recommended path for commercial premises

✕ Higher OTC (RM 6,000 vs RM 3,000) — paid back within 1 month of additional savings vs doing B then upgrading later
